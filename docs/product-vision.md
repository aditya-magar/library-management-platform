# Product Vision & MVP

## 1. Product Vision Statement

"To deliver a modern, automated, and cloud-native Library Management Platform that eliminates manual administrative overhead, streamlines circulation workflows, and delivers an intuitive digital catalog experience for academic communities."

## 2. MVP Scope

The Minimum Viable Product focuses on the core features required to establish the Library Management Platform.

| No. | MVP Feature | Description |
|---|---|---|
| 1 | User Login & Profile RBAC | Role-based access for platform users |
| 2 | Book Search & Availability Status | Search books and view their availability |
| 3 | Basic Issue & Return Transaction Management | Manage basic circulation transactions |
| 4 | Automated Fine Calculation Logic | Calculate overdue penalties automatically |
| 5 | Basic Administrative Reporting | Provide basic administrative reports |

## 3. Deferred Features

Non-essential capabilities such as AI book recommendations and third-party payment gateways are outside the initial MVP scope.
