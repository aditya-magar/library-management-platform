# IBM Design Thinking & IBM Loop

## 1. IBM Design Thinking

IBM Design Thinking scales human-centered design for enterprise software delivery.

### Pillar 1 — Focus on User Outcomes

Technical goals should be connected to measurable user outcomes.

**Feature Goal:**

"Build a catalog database search query."

**Outcome Focus:**

"Enable students to locate and reserve any book in under 3 clicks."

---

### Pillar 2 — Restless Reinvention

Software should continuously evolve based on production usage, user feedback, UI requirements and backend performance.

---

### Pillar 3 — Diverse Empowered Teams

The project requires cross-functional collaboration between:

- Product Managers
- UX Designers
- Software Engineers
- QA Engineers
- Database Administrators
- DevOps Engineers

---

# 2. IBM Loop Engine

The continuous improvement cycle is:

**Observe → Reflect → Make**

### Observe

Study:

- User interactions
- System logs
- Operational friction

### Reflect

- Analyze metrics
- Align priorities
- Re-evaluate requirements

### Make

- Design UI
- Write code
- Automate CI/CD deployment

The loop enables continuous improvement of the Library Management Platform.
